# Ask Hava

Private build repository for Ask Hava (askhava.com), a local quote service for Lake Havasu City.

- **Start here:** `BUILD_BRIEF.md` explains how Claude Code builds the app.
- **Owner setup:** `PHONE_SETUP.md`.
- **Start a build session:** `CC_START.md`.
- **Build status:** `STATUS.md` on the `claude/kit-state` branch, written by the runner every cycle: https://github.com/casey451/askhava/blob/claude/kit-state/STATUS.md
- **What to build:** `sources/01_spec/Changes_Since_v9.3_AUTHORITATIVE.md`, plus the rest of `sources/`, which is read-only.
