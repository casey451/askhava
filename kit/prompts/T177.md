# T177: catalog: load the question bank and the repair, replace and new-install job types, with the no-warranty rule

Task T177 (build, phase 1, stage 2). Slug: catalog-question-bank-load.
Branch: `claude/task/T177-catalog-question-bank-load`
Model: `claude-sonnet-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: licensing).

## Goal

`catalog` loads each category's versioned question set from `docs/catalog/question_bank.yaml` (3 to 8 questions, both languages, card fields multiple choice only) and the repair, replace and new-install job types of the five split categories, and refuses to load any category, job type or offer that covers a home warranty, protection plan or guarantee (LIC-040 to LIC-042). The `kind` field (repair, replace or install) on the five split categories' job types is T233's, which runs first; this task loads it (LIC-041, D-493).
