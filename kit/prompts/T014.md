# T014: core: derived IDs (HMAC) and the webhook dedupe helper

## Goal

`core` derives card, quote, pick and link IDs by HMAC from what they identify plus a server secret (link tokens with a stored per-record salt, so a link can be re-issued and revoked), and gives every webhook handler one dedupe helper so an event processed once changes nothing the next 99 times (CARD-017, PICK-028, SEC-017, SEC-037, SEC-039). This task also owns the quote-page token hashes and salt in `jobs` with an issue/revoke `api` (SEC-037, D-491); `jobs` is created by T031, so T014 depends on it. `core` cannot hold the dedupe insert for another module's table: it gives the outcome type and the `INSERT … ON CONFLICT DO NOTHING RETURNING` pattern, and each module writes its own literal insert into its own `webhook_event` (D-491).
