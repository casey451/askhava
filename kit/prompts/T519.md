## Goal

Plan change D-3878 (Fable's pre-claim check of stage-5 wave 1, Nov 16, 2026): `scripts/check_copy.py`'s `template_blocks` (`:126` to `:138`, run by `scripts/smoke.sh:67` and `Ci`) measures every line of visible text in every `app/*/templates/**/*.html` with no exception, while WORD-029 exempts wording a requirement fixes verbatim (D-482) and its measures (English sentence length, Flesch-Kincaid grade, English claim words) mean nothing for Spanish. The next site pages must carry fixed sentences that fail it: WEB-005's launch-offer line (27 words), WEB-022's 911 note (25), AI-018's switched-off wording (30), WORD-002's Spanish long form (grade 16.6) and, under an English grade formula, most Spanish text. This task makes `template_blocks` skip (1) every `es_*.html` file, (2) text inside an element with `lang="es"` that reads as Spanish (it holds at least one word of a small fixed list of common Spanish words; text in a nested element with another `lang` is measured), and (3) text inside an element marked `data-fixed="<requirement ID>"`, only when the ID is a requirement in `docs/spec/` and the element's visible text, whitespace collapsed and each template expression standing for any one word (the brand name), appears word for word in that requirement's text. A `data-fixed` element naming no requirement, or whose text its requirement does not hold word for word, is reported as a problem, so the marker can never exempt copy no requirement pins. It parses with Python's `html.parser` (no new library), documents the marker in the script's docstring, keeps every other measure, the `docs/copy/site-copy.md` `fixed` tag and `MAX_GRADE` unchanged, and changes no template. Tests in the new `tests/test_check_copy_templates.py` on planted fake templates: a 27-word unmarked sentence fails; the WEB-005 line marked `data-fixed="WEB-005"` passes; a marked sentence its requirement does not hold fails; a marker naming an unknown ID fails; an over-grade passage in a `lang="es"` element and in an `es_x.html` file passes; English text after the `lang="es"` element closes is measured; a `lang="es"` element of 5 words or more holding none of a small fixed list of common Spanish words (de, el, la, los, que, su, para, por, usted, es, y, en) fails, so English cannot escape the check by being mislabelled; the repository's templates still pass (TD-WORD-31). It runs before T102 and T221, the first pages with such sentences, and before T229, the next owner of `scripts/check_copy.py`. The other way (pages passing such sentences as Rust fields) is not taken: `tests/docs/test_required_lines.py` (T202) reads the templates for those lines. Plan change D-3881: each block keeps its `<path> · text <n>` name and numbering, which `tests/test_check_copy.py:66` asserts.
