# T323: ai: a new capitalized name at the start of a sentence counts as an added fact

Task T323 (build, phase 1, stage 4). Slug: adds-fact-sentence-start.

## Goal

Fourth external audit F41 (D-2209; AI-019, D-988): `adds_fact` (`app/ai/src/output_checks.rs:281`) never counts a capitalized word that starts a line or follows `.`, `!`, `?` or `:`, so "Rheem unit is leaking." passes AI-019's "adds no fact" check when her words never named Rheem; the only case plants the name mid-sentence (`app/ai/src/tests/prop_ai_output_limits.rs:220`). After T295 (which owns the file for the brand words): a sentence-start word also counts as a new fact when it is unknown to her words, answers and photo notes and is not an ordinary sentence opener; the openers are a fixed list kept as data (`app/ai/data/sentence_openers.json`, English and Spanish function words, pronouns and the first words of the question bank and card templates; no brand or market name), read once. A sentence-start word that ends in a colon is a label, and the list's labels, "Note" among them, are openers: the done property `a_planted_limit_breach_falls_back` plants every phrase in a sentence starting "Note: " (`app/ai/src/tests/prop_ai_output_limits.rs:112`), and `check_output` runs `adds_fact` before `is_contact` (`output_checks.rs:194` to `:198`), so without it that property's contact cases would end as an added fact, not a contact; a label not on the list counts like any other sentence-start word, so "Rheem: unit is leaking." is refused when her words never named Rheem (AI-019 holds), and TD-AI-26 has that case and "Note: the water heater is leaking." passing (D-3083). Check every fixed Ask Hava text the AI may echo so none trips it. Tests in `app/ai/src/tests/adds_fact_openers.rs` (TD-AI-26): "Rheem unit is leaking." and "Water heater broke. Rheem says so." are refused when her words never named Rheem and pass when they did; "The water heater is leaking." and "¿Cuándo empezó?" pass; every existing `ai` output-check test passes unchanged. Update the `ai` `CLAUDE.md` and `docs/decisions.md`.
