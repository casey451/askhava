## Goal

Twilio's inbound-text and status webhooks reach the app (D-861: no routing task existed): `app/server/src/inbound_text.rs` adds the two POST routes, merged in `build_router` (`app/server/src/lib.rs`, shared), each taking only a delivery the adapter's `X-Twilio-Signature` check (`adapters::api::verify_webhook`) passed, 403 and a log line otherwise (SEC-016, SEC-039). Twilio signs the full public URL it posted to, and no setting holds it yet: this task adds `ASKHAVA_PUBLIC_BASE_URL` to the typed settings in `app/core/src/settings.rs` (a shared path, D-493), read from the environment and never hard-coded, and builds each delivery's URL from it plus the route path and query string and answering 200 whatever the outcome except on a database error. An inbound text runs, in order and once per MessageSid (TXT-012; a status callback once per MessageSid and MessageStatus, SEC-039): `messaging::api::receive_inbound`, `privacy::api::read_inbound` (the raw text goes no further), `messaging::api::on_inbound_text` (an opt-out word ends it there, CON-008), `messaging::api::reply_to_help` (HELP, INFO, AYUDA), then, for a number that is not a linked business phone, `intake::api::receive_reply`; a status callback runs `receive_status`. A text from a linked business phone is recorded and goes to no homeowner path (business replies are later tasks'). `receive_reply` (new, `app/intake/src/replies.rs`) is the dispatcher inside an open request (D-999, D-1199 (4)): a text that is only LIST or LISTA, optionally with a request number, goes to `answer_list` with the businesses' public names (TXT-031); any other reply first calls `hear`, which restarts each Intake job's 72-hour no-reply wait at the reply (INT-019, D-807), then `receive_text` as today, so consent, the 911 screen, CLOSE, cancel and <n> YES keep their owners' paths. The INT-032 "That's 2 jobs" copy and its conversation wiring stay D-999's open gap, not this task's. The worker's handler registry in `app/server/src/lib.rs` already holds `NO_REPLY_KIND`, the off-database stream, `TIMER_KIND` and `quotes::api::WINDOWS_KIND` (D-1216); this task adds routes only, no handler.
