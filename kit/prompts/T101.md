# T101: site: base layout in the design spec's look, works without JavaScript, help in one place

Task T101 (build, phase 1, stage 5). Slug: site-base.

## Goal

The site's base layout (shared template, stylesheet, routes) renders every page server-side without JavaScript in the design spec's plaster-and-brass look, with one `h1`, landmarks, a skip link, `lang` on page and passages, help in the same place on every page, and the introduction-fee line of WEB-026 on the how-it-works page (A11Y-003, A11Y-004, A11Y-017, WEB-001, WEB-026).
