## Goal

`payments.ledger_entry` exists before any task writes a ledger row: an append-only table (the app role can insert and select, never update or delete, D-092) with the FEE-028 entry types, including countering-fee, countering-fee-return and processing-fee, and `payments::api::ledger_append` as the only way to write one, so the free-win, refund, dispute and charge tasks each add their own rows through it and money moves only through `payments` (FEE-028, FEE-032). This task creates the `payments` crate if it is not there yet (`Cargo.toml`, `lib.rs` and `api.rs` are shared paths); the nightly reconcile is T067's (D-491).
