## Goal

`Ci` decides whether to build and test Rust from three path rules in `.github/workflows/ci.yml` (the Checks step at `:127`, Coverage at `:299`, E2e at `:404`) and the copy in `scripts/prehandin.sh:62` (`RUST_PATHS`, kept equal by `tests/test_prehandin.py`). None matches `docs/` or `schemas/`, yet the app compiles in `docs/legal/homeowner-terms.md` (`app/server/src/lib.rs:136`), seven `docs/catalog/*.yaml` files (`app/catalog/src/loader.rs`, `app/licensing/src/class_map.rs`, `app/intake/src/golden_run.rs` and others) and `schemas/intake_reading.json` (`app/ai/src/schemas.rs`), so a change to the Terms or a catalog file alone merges with Checks, Coverage and E2e green having run no Rust (third external audit, D-1867). `a11y.yml` and `twin.yml` have no path rule (they run on every push) and stay as they are. (1) Add exactly `docs/legal/`, `docs/catalog/`, `schemas/` and `docs/architecture\.md` (T284's route table, which its route test compiles in, D-1868) to the three rules and to `RUST_PATHS`; never all of `docs/`. (2) A new guard, `scripts/check_include_paths.py`, run in `Ci`'s Checks job on every push (not behind the path rule) and in `scripts/prehandin.sh --quick`: it finds every `include_str!`, `include_bytes!` and `include!` string path, and every `concat!(env!("CARGO_MANIFEST_DIR"), ...)` path, in `app/**/*.rs` and `tests/{integration,security,recovery,fixtures}/**/*.rs`, resolves each (against its source file, or against its crate's folder for `CARGO_MANIFEST_DIR`), and fails, naming the source line and the resolved file, when a resolved path inside the repository is NOT matched by the Checks rule and by the Coverage rule in `ci.yml` (both read from the workflow file itself, so the rules have one source) and by `RUST_PATHS`; a path that does not exist fails too; a form it cannot resolve (a path built at run time) fails naming the line, so nothing is skipped silently. Tests in `tests/test_check_include_paths.py`: a temporary tree with an included file under a covered folder passes; one under an uncovered folder (`docs/other/x.md`) fails naming the line; a `../` path that resolves outside a covered folder fails; a file covered by the Checks rule but not the Coverage rule fails; `include!` and `concat!(env!("CARGO_MANIFEST_DIR"), ...)` forms are found; a missing file fails; the real repository passes. `tests/test_prehandin.py` keeps `RUST_PATHS` equal to the Checks rule. Update `docs/decisions.md`.

Acceptance: TD-OPS-32 passes (`python3 -m pytest tests/test_check_include_paths.py tests/test_prehandin.py`); on the task's branch, a commit that changes only `docs/legal/homeowner-terms.md` makes the Checks step print `rust=true` (the run named in the hand-in).
