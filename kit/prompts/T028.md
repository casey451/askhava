# T028: messaging: outbox that never sends twice, sender directory

Task T028 (build, phase 1, stage 2). Slug: messaging-outbox.

## Goal

Every outbound text goes through the `messaging` outbox with an idempotency key derived from what it identifies, so a retry or a second worker never sends it twice, and no text goes to a past customer unless they wrote first (TXT-009, TXT-011).
