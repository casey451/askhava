## Goal

`docs/catalog/intake_golden.yaml` holds about 10 fake sample requests per launch-open trade (37 trades, so about 370 rows; the set grows in the re-plan if OPS-040's run needs more), each with the expected trade, job type and questions, and a test loads it and checks every row against the catalog before any routing code exists (INT-040). At least a quarter of each trade's golden rows are in Spanish, and the loader test fails below that (OPS-053, D-492).

Acceptance: `python3 -m pytest tests/test_intake_golden.py` passes: every launch-open trade has about 10 rows, each row's trade, job type and questions exist in the catalog, and every value is fake.
