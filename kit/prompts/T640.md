On a `claude/train/` ref the script proves nothing; D-489 applies to X as on any branch. (2) `ci.yml`: "Plan lock and change rules" is today the only Checks step that fetches origin/main (`ci.yml:128` to `:136`), and the delete guard (`:146`, `git cat-file -e origin/main:$f`, which passes when origin/main is missing: it fails open), the merge-base at `:166` and the named mutants' `--base origin/main` (`:297`) all need it.
