## Goal

Plan change D-3263 (TXT-021, TXT-034; D-491, D-2821). An end-to-end spec can read the texts the fake carrier accepted (`control.sentTexts`, `tests/e2e/fixtures.ts`) but no email: the stand-in serves only `POST /resend/emails` (`stand_ins/server.py:356`), though `FakeResend` keeps every accepted send in `sent` (`stand_ins/resend.py:55`), so TD-TXT-15's web-and-email journeys (T222, T118, T119) cannot check a quote, safety or job-card email. (The pick code by email is not a Resend email: it goes through Twilio Verify's email channel, `app/picks/src/email_code.rs:113`, and a spec reads it with `GET /_stand_in/twilio/code`, `stand_ins/server.py:344`.) Those email checks also wait for a task that wires outbound email sending, which no task does yet (D-3186); this task only makes them readable once one exists. (1) `stand_ins/server.py`: a control route `GET /_stand_in/resend/emails` (no credentials, like the other `/_stand_in/` paths) answering `{"emails": [...]}` from `FakeResend.sent`, oldest first, each with `id`, `from`, `to`, `subject`, `text` and `html`, filtered by an optional `to` query (an address in the list); `stand_ins/resend.py` is not changed. The route goes in the `ROUTES` table, owned here before T131 and T335, which also add routes there (D-2821). (2) `tests/e2e/fixtures.ts`: `control.sentEmails({ to? })`, reading that route at the stand-in's origin (`http://127.0.0.1:4010`, the port `tests/e2e/webserver.ts` starts it on, named once as a constant with that note), typed as `SentEmail`; `sentTexts` and the clock calls are unchanged. (3) `tests/contract/test_stand_in_sent_emails.py`: a send through the stand-in is listed once with its fields, a replayed idempotent send is not listed twice, the `to` filter keeps only that address's emails, and an empty log answers an empty list. Fake addresses only (`example.com`). A harness task because `stand_ins/` is protected and `tests/e2e/fixtures.ts` is DONE T020's. Update `docs/decisions.md`.

Acceptance: `tests/contract/test_stand_in_sent_emails.py` passes against the stand-in server; `tests/contract/test_stand_in_server.py` and every other stand-in and e2e test passes unchanged; `control.sentEmails` is typed and lint-clean.
