# T334: payments: the nightly reconcile catches up after an outage from its last good run, reads Stripe in pages, and checks refund amounts

## Goal

Sixth audit U-07 and U-05's reconcile half (D-2304, D-2303; FEE-029, FEE-051, FEE-028). After T288 (which keeps unsettled charges open) and T333: (1) `LOOKBACK` is 7 days (`app/payments/src/reconcile.rs:57`), so a charge whose events all fell before a reconcile outage of more than 7 days is never read. `migrations/0178_payments_reconcile_checkpoint.sql` adds `payments.reconcile_checkpoint` (one row: the start of the last run that finished; app role SELECT, INSERT and UPDATE of that column only); each run reads every charge created since the earlier of now − 7 days and that time − 1 day, with no cap (the charge list, `GET /v1/charges` with `created[gte]`, has no 30-day limit), so no charge is skipped however long the outage; when the gap since the last finished run is over 2 days it also raises one High `payments.reconcile_gap` alert, as information only (it skips nothing); the checkpoint moves only when a run finishes. (2) `ReconcileStripe::list_charges` (:63) returns an unbounded `Vec`; it becomes a paged read (`since`, a cursor, a page size of at most 100) and the run handles one page at a time in bounded batches, committing page by page, so memory and transaction size do not grow with volume; the FEE-030 cent-match totals (gross charges, refunds, disputes, fees) accumulate across pages and are compared once at the end of the run. (3) `own_refund` (:357) records a refund at the charged amount; it uses T333's check: a reported amount that differs or a currency other than `usd` records Stripe's amount and raises the same High alert. Tests in `tests/integration/tests/reconcile_catch_up.rs` (TD-FEE-60) with the fake `ReconcileStripe`: a 10-day outage reads back to the checkpoint less a day; a 40-day one reads every charge back to its checkpoint and raises the information alert once; the cent match over several pages equals the match over one; 250 charges are read in three pages; a partial refund found by the reconcile alerts; a failed run leaves the checkpoint. T335 implements the paged read over HTTP. Money: the overseer runs an independent money review of the hand-in. Update the `payments` `CLAUDE.md`, `docs/architecture.md` section 3 (the new table) and section 10, and `docs/decisions.md`.
