# T233: catalog: the repair, replace and install kind on the five split categories, with its check

## Goal

This task adds a `kind: repair | replace | install` field to each job type of the plumbing repair, heating and cooling, electrical, roof repair and painting categories in `docs/catalog/categories.yaml`, splitting job types into repair, replace and new-install ones where the license rule allows, and a matching check in `scripts/check_catalog.py`: a job type of those five categories without a kind, or one of those categories with no repair kind, fails, so TD-LIC-16 has its oracle (LIC-041). `categories.yaml` and `check_catalog.py` are locked in `kit/plan.lock`: this task's PR rewrites the lock with `python3 scripts/check_plan_lock.py --write` together with its `docs/decisions.md` entry. `tests/test_check_catalog.py` is protected: a missing case is reported for a harness task, never written here. The categories change makes the Twin gate's generated license oracle `twin/oracle/license_scope.json` stale (its `sources` hash and the job types it grants), so this task also owns that file, for one purpose: after the categories change, run `python3 twin/oracle/gen_license_scope.py` and commit its output unedited; never edit it by hand, and never change `twin/oracle/gen_license_scope.py` or anything else under `twin/`. The file is protected, so this is a harness task with an Opus review (D-677). Split from T177, whose context would otherwise pass 20%. (D-493)

Acceptance: `python3 scripts/check_catalog.py` passes on the real catalog, and fails on a planted job type of one of the five split categories with no `kind` and on one of those categories with no repair kind; `python3 -m pytest tests/test_check_catalog.py -q -p no:cacheprovider` passes; after the categories change `python3 twin/oracle/gen_license_scope.py` was run and its output committed, so `python3 twin/oracle/gen_license_scope.py --check` and `PYTHONHASHSEED=0 python3 twin/gate.py` pass (D-493, D-677).
