## Goal

Plan change D-4052 (Casey's outside code audit, batch B, Nov 17, 2026; each item re-checked on `main` 67f601a before planning): (B19) `app/calls/src/voice.rs:147`, `:250`, `:691` and `app/calls/src/lifecycle.rs:324` put brand words, spoken lines and action URLs into TwiML unescaped, while `routing.rs` already has `xml_escape` (`app/calls/src/routing.rs:322`). Today every input is config or app-built, so this is hardening: `xml_escape` moves to one `pub(crate)` helper the four sites and `routing.rs` use, every interpolated value is escaped, and the TwiML for today's brand is byte for byte unchanged. (B23) `refuse_line` (`app/calls/src/service.rs:164` to `:175`) raises a new High `calls.pool_exhausted` alert on every refused call while the pool is full, so a busy evening gives Casey a pile of the same alert; it uses `ops::api::raise_alert_once` (`app/ops/src/api.rs:351`, subject a fixed pool subject), so one stays open until acknowledged. (B35) the read-back's `street_of` (`app/privacy/src/readback_reader.rs:47` to `:50`) cuts at the first comma; intake keeps the address as typed (`split_name_address`, `app/intake/src/rules.rs:498`), so a street line with no comma before the town, state and ZIP is read back whole, town and ZIP included, where CALL-005 says first name and street. With no comma it cuts after the last street-type word (St, Street, Ave, Rd, Dr, Ln, Blvd, Way, Ct, Pl, Cir, Hwy and their full forms, any case), else drops a trailing ZIP and state; the business on that line already holds the job address (CALL-005 runs only for a paid or $0-decided pick), so this is CALL-005's letter, not a leak. Tests, fake data only: the street cuts in `readback_reader.rs`'s own `#[cfg(test)]` module (a comma address, a no-comma address with town, state and ZIP, one with no street word); escaping (a `&`, `<` and a quote) in the new `app/calls/src/tests/twiml_escape.rs` (one `mod` line in the shared `app/calls/src/tests/mod.rs`) with the TwiML for today's brand unchanged; and in the new `tests/integration/tests/pool_alert_once.rs` two refused calls with a full pool raise one open alert. `voice_call_plan.rs`, `number_pool.rs` and the read-back tests pass unchanged.

Acceptance: `tests/integration/tests/pool_alert_once.rs`, `app/calls/src/tests/twiml_escape.rs` and the new read-back unit tests pass, the alert and street cases failing on `main` before the change; every existing `calls` TwiML test passes byte for byte unchanged.
