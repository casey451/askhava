# T076: calls: masked numbers from a fixed pool, PIN sharing when exhausted

Task T076 (build, phase 1, stage 4). Slug: calls-pool.

Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: privacy).

## Goal

`calls` gives each connected job a masked number from the fixed pool in settings (never bought by the app), one no other active job of the same homeowner or business is using where possible, shared with PIN routing and an alert when the pool runs out, on standard programmable voice only, so neither side sees the other's number (CALL-001, CALL-002, CALL-017, CALL-021). The new `calls` schema's default privileges give `askhava_app` SELECT and INSERT only (`ALTER DEFAULT PRIVILEGES IN SCHEMA calls GRANT SELECT, INSERT ON TABLES TO askhava_app`), and a table that needs UPDATE or DELETE gets an explicit GRANT in this migration; T250's `schema_grants.rs` checks every schema's default (D-1520).
