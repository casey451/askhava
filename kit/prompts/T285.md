The plan-health check (D-1350) and the plan-gap hold are unchanged; no second repair path is built. Unit tests in `tests/test_runner_owned_gap.py` with the fake `Env`: all present (DONE, no mark, no outbox); one missing file (DONE, mark, one outbox item, lane free for the next claim); a missing folder; an unwired route row; an empty hand-in and FIX-MAIN skipped; the mark cleared by the file arriving, by a plan change moving it, and kept on a git error; STATUS.md shows the line.
