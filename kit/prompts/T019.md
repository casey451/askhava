## Goal

The production image is built from a Dockerfile whose base images are pinned by digest, with separate web and worker commands, and a security test fails on an unpinned image; the audit tools and pinned Actions are part of the same supply-chain rule (SEC-021, SEC-045). TD-SEC-24's docs test, in this task, covers the Dockerfile (base image by digest); the workflow `uses:` SHA cases are T169's and T121's (D-491). Per the second trial (D-491): cargo-chef stages, `debian:trixie-slim` by digest with `ca-certificates` and `libssl3t64`, user 10001, `RUSTUP_TOOLCHAIN` set in the builder, no `# syntax=` line; both binaries (the shared `app/server/src/main.rs` and `app/server/src/bin/worker.rs`, edited here) handle SIGTERM and the web binary binds `0.0.0.0:$PORT`.
