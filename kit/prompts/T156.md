## Goal

Intake asks the request's question set one at a time in the INT-043 order with numbered answers and "Not sure", rewording within AI-019 only while AI is on, never more than 8; routing confidence decides when the trade and job-type questions are asked and when a job goes out as "Job type not certain" (INT-039, INT-040, CARD-007). The skip threshold is unset until a recorded real-model run (AI-027) sets it, so until then the AI skips no question (INT-039, D-492). `app/intake/src/golden_run.rs` runs the golden set (`docs/catalog/intake_golden.yaml`) whenever the catalog version changes and stores each run's share in this task's migration (`intake.golden_result`), which T210's monthly report reads through `intake::api` (OPS-040, D-493).
