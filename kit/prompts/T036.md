# T036: licensing: daily list imports and the license class from the state record

Task T036 (build, phase 1, stage 2). Slug: licensing-imports.
Branch: `claude/task/T036-licensing-imports`
Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: licensing).

## Goal

`licensing` imports the ROC and city lists daily, takes each business's license class from the state record (never typed, pest attested), uses the lists for verification only, gives the sign-up read-back of what the license covers, and sends a card only to a business whose latest daily check was Active (CARD-015, LIC-006, LIC-007, LIC-010, LIC-027).

Acceptance: The daily import job reads a fixture list, records each row with its source and date, and derives the license class from the state record; a planted malformed row is skipped and counted, never crashing the import; `cargo test -p askhava-licensing` is green.
