# T052: portals: the homeowner quote page (token, arrival order, no contact details)

## Goal

The homeowner's quote page, reached by an unguessable salted 128-bit token that stops working 30 days after close, shows every eligible quote numbered in arrival order with the WORD-005 lines, adds quotes as they arrive with a Pick button from the first one, marks an ineligible business's quote "no longer available", and shows no names, phones or addresses (PICK-008 to PICK-012, WORD-005, SEC-037). Every quote-page line other tasks' rows used to check is this task's (TD-PICK-38): the no-ranking top line, "#1 means first received, not first choice.", no rating, review or hire count, no summary element while AI quote summaries are off, the LIST line, and the CON-028 "still open" line after an opt-out; a cross-site POST to the quote page is refused (TD-PICK-05) (D-491). New quotes are added by `app/portals/static/quote_page.ts` (compiled by `tsc`), which polls the page's own quote list, writes one short summary line per batch into the status region (A11Y-033) and leaves the page fully usable without JavaScript (D-492). Each Pick button has the line "or reply <n> YES" beside it (PICK-015, D-247, D-446, TD-PICK-04) (D-493).
