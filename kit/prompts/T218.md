## Goal

A docs test fails any business page, template or document that uses a lead-selling phrase ("ready to hire", "serious homeowners", "qualified", "pre-qualified", "high-intent", a promise of jobs) or a win rate not computed from the ledger; a template test fails any notice holding a recruiting, referral, discount, survey, new-feature or social-media invitation from the list in docs/ai_smell.yaml; and a docs test over the template files reports every template's encoding and segment count and fails when the English consent text needs UCS-2 or more than 2 segments, or when any template grows past the segment count recorded beside it (TXT-044) (WORD-030, TXT-046, TXT-044). Turning Spanish conversations on without the campaign note and sample recorded is refused in code (TXT-043's code half; the campaign document is T113's, TD-TXT-26) (D-493).
