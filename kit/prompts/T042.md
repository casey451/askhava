# T042: intake: trade question, word answers and the keyword second opinion

Task T042 (build, phase 1, stage 2). Slug: intake-trade-matching.
Branch: `claude/task/T042-intake-trade-matching`
Model: `claude-opus-5-5`, effort high. Reviewer: `claude-opus-5-5` (areas: licensing).

## Goal

Each request is read twice with the keyword rules as an independent opinion; when the trade is in doubt a numbered trade question offering every distinct trade (up to three) is asked, word answers are matched as whole words, a re-ask repeats the options, and two unusable answers apply the D-103 fallback so intake moves on (AI-011, INT-012, INT-013, INT-015). With the keyword reading built here, this task also applies INT-010's after-2-hours rule (a same-trade message joins only when at least half its words appear in the job's scrubbed description) and INT-032's two-trade detection with the "That's 2 jobs" reply and ALSO (or TAMBIÉN) starting the second job (D-493).
