# T288: payments: a Stripe charge the nightly reconcile cannot settle is kept and retried until it is, with an alert

Task T288 (build, phase 1, stage 4). Slug: reconcile-open-charges.

## Goal

The nightly reconcile reads only charges created in the last seven days (`LOOKBACK`, `app/payments/src/reconcile.rs:51`), so a charge whose ledger write failed, or whose auto-match or refund did not finish, and was not settled within those seven nights is never looked at again, and the difference stops being visible (third external audit, D-1872). (1) `migrations/0173_payments_reconcile_open.sql`: `payments.reconcile_open`, one row per Stripe charge the run could not settle (charge ID, its PaymentIntent and the pick its metadata names, the amounts the run read, `first_seen`, `last_tried`, `tries`, the last refusal's code name, `alerted_at`, `settled_at`), no homeowner or business contact detail, the app role SELECT, INSERT and UPDATE of the try, alert and settle columns only. (2) Each run records every charge it read but could not settle (an append that failed, an auto-match with no pick, a refund that did not succeed, a mismatch) and retries every unsettled row, whatever its age, from its stored facts after reading the charge's current refund and dispute state again (a charge refunded or disputed since it was stored is settled by that state, never refunded twice), with the same ledger and refund keys the live writers use (so a retry never appends or refunds twice, TD-FEE-16), setting `settled_at` when it settles. (3) A row still unsettled 7 days after `first_seen` raises one High alert (an `ops` alert with the row's ID only, OPS-029's ledger-difference push), set once with `alerted_at` in the same transaction so a later run never raises it again, and the run's report counts open rows. `LOOKBACK` stays 7 days. Tests in `tests/integration/tests/reconcile_open.rs`. Update the `payments` `CLAUDE.md` and `docs/decisions.md` (`docs/architecture.md` section 3 already lists the new table, D-1872).

Acceptance: TD-FEE-49 passes against PostgreSQL with a fake `ReconcileStripe`; every TD-FEE-16 and `tests/integration/tests/reconcile.rs` case passes unchanged.
