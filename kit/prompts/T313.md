(4) Fifth external audit AH-001 (D-2266): also register `messaging.charge_receipt` (`run_receipt_email`, `app/messaging/src/receipt_email.rs:187`, queued by `picks::money_notices`) with a `ReceiptSender` built from the same postal-address setting (D-1826 (1)), and prove in the same test file that a receipt event reaches the fake email provider once through the worker (TD-FEE-55).
