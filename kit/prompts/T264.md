## Goal

`scripts/coverage_floor.py` `judge` checks a floor only when the report measured it, so a built crate missing from the report, a wrong path prefix or an empty report passes; and `tests/coverage_floor.json` keeps the total at 0.0, D-694's skeleton value that the first covered code was to raise (external audit A05 and A06, D-1759). (1) A floor whose path exists on disk and is absent, or measured with zero lines, in a full report fails; a report with no files or zero total lines fails; a `--only` run fails when a selected prefix is absent; a path not on disk passes only when it is listed in a new `future` list in the floor file with a reason, shown in the output. (2) Remove the `app/catalog/src/rules.rs` key: the fee rules are `app/payments/src/rules.rs`, inside the `app/payments/` 95 floor (D-694, D-1286, D-1440). (3) Set `total` from `Ci`'s Coverage job on `main` (a named run ID and its printed total, recorded in the decision; never a number worked out from line counts), rounded down to a whole percent less 2 points, and make `lowered` also refuse a `future` entry added for a path that exists. Tests in `tests/test_coverage_floor.py`: absent built crate, wrong prefix, empty report, an intentional future path, a zero-branch part measured by lines, a `--only` run, and the measured floor itself.

Acceptance: TD-OPS-30 passes (`python3 -m pytest tests/test_coverage_floor.py`); `Ci`'s Coverage job is green on the task's head with the raised total.
