## Goal

Plan change D-3497 split T361 in two (D-2632; PICK-008, PRIV-005): T361 stores each quote's shown number, orders `page_quotes` and the LIST by it, gives a `quotes::api` read of the shown numbers and a `picks::api` business-bound pick entry point that answers `Taken` when a number no longer maps to the business; this task makes the pages use them. The quote page numbers each quote by its shown number through T361's read and a new numbering function beside `portals`' `number_quotes` (`app/portals/src/quote_page.rs:61`, rendered at `:257`), which keeps its signature for `app/portals/src/tests/prop_arrival_order.rs` (D-3144); a withdrawn quote keeps its place and number, shown as "Withdrawn by the business". The review, pick and code forms (`app/portals/templates/quote_page.html`, `pick_review.html`, `pick_code.html`, posted to `app/portals/src/pick_flow.rs`) carry the business the number was shown for, in the form T361's entry point takes, and `pick_flow.rs` calls that entry point and treats `Taken` as it treats any quote that can no longer be picked, so nothing is stored, notified or charged for another business. Tests in `tests/integration/tests/pick_bound_forms.rs` (TD-PICK-64) against real PostgreSQL, fake data only. Every TD-PICK case passes unchanged. Update the `portals` `CLAUDE.md` and `docs/decisions.md`. Plan change D-3878: after T361, `page_quotes` still lists in arrival order and `page_pick` still resolves a list position, so this task's numbering function orders by the shown number itself and the pick forms post only through T361's business-bound entry point. Plan change D-3879 (Fable's pre-claim check of stage-5 wave 2, Nov 16, 2026): Done tests post `quote=N` with no business field (`tests/integration/tests/page_pick.rs:131`, `:139`, `pick_contact_choice.rs:124`, `:343`, `tier_pick_pages.rs`, `share_and_cant_take.rs:264` to `:339`, `backup_choice.rs:298`, `:309`, `tests/security/tests/page_pick_privacy.rs`, `quote_token.rs:168`, `auth_matrix.rs:463`), and `PickForm` and `CodeForm` are `deny_unknown_fields` (`app/portals/src/pick_flow.rs:131`, `:840`). The business field is optional on all three forms (`#[serde(default)]`). A post without it resolves the number to its business through T361's shown-number read (a shown number never moves, so the mapping cannot shift) and then calls the business-bound entry point; a post whose field names another business than the number's is `Taken`. The done tests that post `quote=N` alone pass unchanged. The two `number_quotes` calls in `pick_flow.rs` (`:553` for the packages, `:807` for the available numbers) move to the new numbering function, so the page, the packages and the pick all use the shown number. Plan change D-3999: T361 was split; the shown-number LIST, the text pick and the business-bound entry point this task uses are T564's, so it follows T564.
