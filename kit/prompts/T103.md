# T103: site: web chat with the consent text first, typing a verified mobile number is the opt-in

Task T103 (build, phase 1, stage 5). Slug: site-web-chat.
Branch: `claude/task/T103-site-web-chat`
Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: compliance, privacy, security).

## Goal

A homeowner can start a request by web chat as well as by text: the consent text sits above the chat box with no agree button, the opt-in is typing a mobile number and then its code (no AI call before the code), business-intent messages are detected on both paths (the text path's check lives in `app/intake/src/conversation.rs`, extended here), and a `g` link code is recorded with the request and nothing else tracked (CON-025, INT-001, INT-020, INT-047, AI-021). While the AI-008 switch is on, the chat page shows "An AI service helps word our questions." above the chat box (AI-026, D-492). The request page shows the full consent text (WEB-014's request-page clause; the legal pages are T221's) (D-493). This task's migration adds the request source column INT-047 records (the `g` link code, or 'text' for a request started by text), which T158's scorecard reads (D-493). The WEB-006 Spanish consent draft sits above the English consent text on the request page (D-493).
