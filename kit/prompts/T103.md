# T103: site: web chat with the consent text first, starting the chat is the opt-in, a typed number verified by code first

Task T103 (build, phase 1, stage 5). Slug: site-web-chat.
Branch: `claude/task/T103-site-web-chat`
Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: compliance, privacy, security).

## Goal

A homeowner can start a request by web chat as well as by text: the consent text sits above the chat box with no agree button, the opt-in is typing a mobile number and then its code (no AI call before the code), business-intent messages are detected, and a `g` link code is recorded with the request and nothing else tracked (CON-025, INT-001, INT-020, INT-047, AI-021).
