# T023: privacy: inbound reader, ScrubbedText and the plain-code scrubber

Task T023 (build, phase 1, stage 2). Slug: privacy-scrubber.
Branch: `claude/task/T023-privacy-scrubber`
Model: `claude-opus-5-5`, effort high. Reviewer: `claude-opus-5-5` (areas: privacy, security).

## Goal

`privacy` is the only code that reads raw homeowner text, including inbound email through the signed webhook, and turns it into `ScrubbedText`, a type no other crate can build (compile-fail proof), after the plain-code scrubber removes names, phone numbers in any spelling, emails, handles and street numbers with NFKC normalization, so the `ai` module never receives unscrubbed text (AI-001 to AI-004, AI-009, AI-020, INT-012, PRIV-026).
