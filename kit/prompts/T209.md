# T209: picks and payments: the optional auto-confirm-and-pay box with one off-session charge

Task T209 (build, phase 1, stage 4). Slug: picks-auto-confirm.

## Goal

A business may tick auto-confirm-and-pay on a quote, after a fresh Verify code, only while Stripe's written answer is filed; a portal pick then makes one off-session charge and any failure falls back to the normal Confirm step; a text pick never auto-charges; and no other code path charges off-session (PICK-048, PICK-056, FEE-014, SEC-038). The box is on the quote form (`business_actions.html`, `business_actions.rs`); its tick is stored with the quote by `app/quotes/src/auto_confirm_box.rs` in the `quotes` schema and read by `picks` through `quotes::api`, while whether the box shows (Stripe's written answer filed and a saved card on file, through `catalog::api` and `payments::api`) is decided by the portals route, never by `quotes`; Stripe's written answer is a `catalog` setting (date, reference, answer) read through `catalog::api` by `payments::off_session` and the portals route, which the owner portal's settings page (T108) files later, so the tests insert it directly (D-491). The off-session charge passes the same hard monthly-limit admission as a press (`begin_attempt`'s reservation, T263, D-1758). T301 serves the email action links (D-2128): keep the signatures `app/server/src/action_links.rs` calls; any page or action this task adds is served by T306, not by a `.route` in `server`.
