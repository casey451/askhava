# T193: businesses: sign-up screens for someone else filling in, the masked record contact, the review target, the fee summary and the done screen

Task T193 (build, phase 1, stage 4). Slug: businesses-signup-screens.
Branch: `claude/task/T193-businesses-signup-screens`
Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: money, security, accessibility).

## Goal

Anyone may fill in the form but the code goes only to the record contact; the masked contact and its kind show before a code is sent; a needs-review sign-up gets a decision target of 4 days; the plain-words fee summary sits above the Terms link; and the done screen gives the trade's business count (BIZ-024, BIZ-026, BIZ-027, BIZ-030, BIZ-031). The sign-up screens are the portals page `business_signup.html` with its route `business_signup.rs`, which reads the open-jobs count of BIZ-031 through `quotes::api` (`businesses` cannot call `quotes`, D-491). The sign-up screens show the WEB-024 notice line that follows the business-texting switch (D-493). This task's migration stores the "That number is old" waiting-on-record status that resumes the sign-up when the next daily list shows a new contact (BIZ-026) and the sent-once flag of BIZ-031's email (D-493).
