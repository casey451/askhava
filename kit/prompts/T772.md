## Goal

Plan change D-5017 (T664's confirmed plan gap; PICK-020, PICK-046, PICK-047; D-056, D-4349). `picks.pick.confirm_due` is read only by private code (`store_due`, `hold_row` in `app/picks/src/handlers.rs`) and the tail that returns the job to Quotes ready and queues her text (`end_waiting` in `cant_take.rs`, `lapse_at` in `handlers.rs`) is crate-private, so T664's press cannot do PICK-020. The new `app/picks/src/confirm_refused.rs` adds, exported by one `mod` line in the shared `lib.rs` and one `pub use` in the shared `api.rs`: (1) `confirm_deadline(db, pick) -> Result<Option<Timestamp>, PicksError>`, the stored `confirm_due` of a pick still awaiting confirm; `None` when the window has not started or the pick no longer waits. (2) `refuse_confirm(tx, (pick, job), refusal, paused, (actor, at)) -> Result<Backup, PicksError>`, in the caller's transaction: calls `refused_at_confirm`, then, as `lapse_at` does, moves the job from Awaiting confirm to Quotes ready only when no pick then waits (`MovedOn` is `PicksError::MovedOn`), and after that last move calls `queue_backup_text`; `Backup::Done` queues nothing. It closes no PaymentIntent (the caller does) and changes no existing file besides the two shared lines. Licensing code, 95% branch coverage shown in the hand-in. Tests in the new `app/picks/src/tests/confirm_refused.rs` (one line in the shared `tests/mod.rs`), PostgreSQL, fake data only. Update `app/picks/NOTES.md` lines for this file only if the task may; else `docs/decisions.md`.

Acceptance: The new tests pass against PostgreSQL: an expired, an account and a license refusal each end the pick, move to the backup or return the job to Quotes ready, and queue the PICK-047 or PICK-046 text once; a paused job gets no PICK-046 text; a pick no longer waiting changes nothing; `confirm_deadline` returns the stored end and `None`.
