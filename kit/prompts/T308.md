## Goal

JOB-019 names "the close button on the quote page" and `intake::api::close_from_page` exists (T049, tested in `tests/integration/tests/close_which.rs`), but the served quote page (`app/portals/src/quote_page.rs`, `quote_page.html`) shows no close button and no route calls it (D-2128). Add the button to the quote page of a job that is not yet final, as a form with its CSRF token posting to a new route constant `CLOSE_ROUTE` (`/q/{token}/close`) in `quote_page.rs`, handled in `quote_page_routes` (not on `QUOTE_PAGE_ROUTE`, whose `POST` is `pick_flow_routes`' review step, both merged in `server::build_router`, so a second `POST` there would collide): it calls `close_from_page` for the token's job, then shows the page saying it is closed, sending no text; a second press or a job already final changes nothing; the `POST` passes `refuse_cross_site` and the CSRF check, and a refusal is a security event (SEC-042, SEC-048). T246's pick form keeps its own path. The page state with the button goes in the shared `tests/a11y/page_states.ts`. Tests in `tests/integration/tests/quote_page_close.rs` (TD-JOB-16). Update the `portals` `CLAUDE.md`, `docs/architecture.md` and `docs/decisions.md`. Plan change D-3877 (Fable's pre-claim check of stage-5 wave 0, Nov 15, 2026): (1) In `tests/security/tests/auth_matrix.rs` only `send`'s extra-field choice (`:458` to `:464`) changes: a path ending `/close` posts no extra field, as `/c/` does, because `ButtonForm` refuses an unknown field (`#[serde(deny_unknown_fields)]`, `app/portals/src/security.rs:377`); no other assertion changes. The close form is `security::ButtonForm` through `CsrfForm`. (2) The `POST` answers 200 with the quote page itself (no redirect), also for a job already final; an unknown token is a bare 404 after the CSRF check. (3) Add no field to `PageView` (`app/portals/src/quote_page.rs:133`; `app/portals/src/tests/prop_arrival_order.rs:99` builds it literally); new state goes on `ShownPage` (`:220`). It is a harness task only because `auth_matrix.rs` is a done task's test (`scripts/validate_tasks.py:608` to `:612`).
