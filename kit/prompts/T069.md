# T069: picks: release only on paid or free; never the homeowner's phone

Task T069 (build, phase 1, stage 3). Slug: picks-release.
Branch: `claude/task/T069-picks-release`
Model: `claude-opus-5-5`, effort high. Reviewer: `claude-opus-5-5` (areas: money, privacy).

## Goal

`picks` releases the first name, address and chosen email to the signed-in business portal only with a `ReleaseProof` (paid, or a recorded $0 fee decision), the release email carries no homeowner detail, and the homeowner's phone number is never released to anyone (PICK-022 to PICK-024, PRIV-005, PRIV-020, BIZ-014). The release email is a `core.task` event a `messaging` handler sends through T094's pipeline: `picks` resolves the recipients through `businesses::api::notice_addresses` (T220's) for the release purpose and puts them in the payload as opaque address IDs, since `messaging` never calls `businesses` (T149 adds backup addresses there) (D-491). On an emergency job, an acceptance before the address arrives releases nothing until the address is in, and the homeowner is asked for it again at once (TD-INT-34, D-492).
