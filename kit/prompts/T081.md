# T081: businesses: sign-up, identity chain from public records, activation

Task T081 (build, phase 1, stage 4). Slug: businesses-signup-identity.

## Goal

Sign-up creates a Stripe customer with no card, starts from the category list, asks the optional source question, requires a verified email, and checks identity by the chain (Verify text to the record phone, then the record email, then a letter); a business activates automatically only when the code and the license or city-list match pass with no flag, and a needs-review sign-up is told its status (BIZ-001 to BIZ-003, BIZ-016, BIZ-019 to BIZ-021, BIZ-053).
