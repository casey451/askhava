# T081: businesses: sign-up, identity chain from public records, activation

Task T081 (build, phase 1, stage 4). Slug: businesses-signup-identity.

## Goal

Sign-up creates a Stripe customer with no card, starts from the category list, asks the optional source question, and checks identity by the chain (Verify text to the record phone, then the record email, then a letter); a business activates automatically only when the code and the license or city-list match pass with no flag, and a needs-review sign-up is told its status (BIZ-001 to BIZ-003, BIZ-016, BIZ-019 to BIZ-021, BIZ-053); sign-up hands the FEE-011 free-win entity keys (ROC number, city-list entity, identity-code contact, city-list owner name) to `payments::api` (T061); the "About us" line (BIZ-022) is stored in `about_us.rs` and screened there with the PICK-007 contact and channel rules and the WORD-003 claims list, since `businesses` cannot call `quotes`; the verified-email check before activation (BIZ-040) is added to `identity.rs` by T196, which builds the verification (D-491). Each business terms acceptance stores the TERMS-033 record: document, version, SHA-256 of the published text, language, channel (business sign-up; the Confirm-page record is T232's, D-493), the assent line shown, time and the business-person ID (D-492).
