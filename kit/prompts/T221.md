## Goal

laftly.com serves /terms, /privacy, /sms-terms, /your-data and /business-data in English from the drafted legal documents in `docs/legal/`, rendered at build time by `app/site/build.rs` with `pulldown-cmark` (allowed by D-491) into Askama pages, the build failing if a document is missing; the two data pages also exist in Spanish (TERMS-021, TERMS-023; the terms, privacy policy and SMS terms have no Spanish source yet); each page carries the WORD-002 footer statement, the data pages and the help-page link hold the AI-018 switched-off sentence while the AI switch is off, and the consent text's links resolve (WEB-014, TERMS-021, TERMS-023, AI-018). The Stage 0.5 static set is T116's (D-491). Each published version of the four documents is kept once in `docs/legal/published/versions.json` with its full text and SHA-256, and a docs test fails if a published version's text no longer matches its hash (TERMS-034, D-492). Its routes pass T348's doors unchanged: `tests/security/tests/auth_matrix.rs` classifies each and `app/server/tests/door_matrix.rs` probes each `yes` row of `docs/architecture.md` section 13 over HTTP (D-2440); this task edits neither, and a route whose path parameter the probe cannot fill is reported, not worked around. Plan change D-3144: (1) `/terms` (one section 13 row) serves both terms documents on one page, the homeowner terms first and then the business terms, each its own section with its own heading, anchor (`#homeowner-terms`, `#business-terms`) and version line. (2) A version counts as published only after Casey's publishing go (WEB-013, WEB-017; `docs/legal/README.md`: none is published yet), so `versions.json` starts as an empty list and the docs test checks its shape and every entry's hash; the publishing change adds each document's entry. (3) `site` may not call `ai` (`kit/layers.json`), so the AI-018 switch is read through a new `intake::api::ai_on(db, env)`, true when `ai::api::ai_mode` (`app/ai/src/switch.rs:129`) is `AiMode::Ai`, a one-line wrapper this task adds to the shared `app/intake/src/api.rs`; T201 and T103 read it too. (4) The pages extend T101's `site_layout.html` and fill `banner_shown`. Plan change D-3155: `build.rs` also renders `docs/legal/accessibility-statement.md` for T115's `/accessibility` page (no route here).
