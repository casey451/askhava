# T017: ops: audit stream, request log and AI readings written off-database

Task T017 (build, phase 1, stage 2). Slug: ops-offdb-stream.

## Goal

The audit stream, the web request log and the AI structured readings are written to object storage as they happen through a write-only, prefix-scoped token, the audit stream carrying a hash chain verified nightly and the request log kept 30 days, so a restore can be replayed (OPS-010, OPS-011, PRIV-029). `ops` only enqueues the stream event on `core.task`, through a function this task adds to `ops`' `api.rs` (a shared path) and T015's audit write calls; the writer is a `server`-registered handler (`app/server/src/offdb_stream.rs`) that calls the storage adapter, since `ops` may call nothing (D-491).
