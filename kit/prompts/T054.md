# T054: picks: pick code (6 digits, 10 minutes, 5 tries, cooldown) and text picks

Task T054 (build, phase 1, stage 2). Slug: picks-code.
Branch: `claude/task/T054-picks-code`
Model: `claude-opus-5-5`, effort medium. Reviewer: `claude-opus-5-5` (areas: privacy, security).

## Goal

`picks` requires a 6-digit Verify code to pick on the page (10 minutes, 5 tries, 15-minute cooldown, paste and autofill allowed, a voice code only on the homeowner's tap, Verify sends capped as PICK-055 says), and handles "<number> YES" text picks: only with exactly one job in Quotes ready, a second YES replacing a waiting pick, and a status reply when nothing waits (PICK-013 to PICK-015, PICK-031, PICK-032, PICK-036, PICK-055). `picks` reacts to intake's opt-out event (CON-029, T050): when a job is paused by the homeowner, a pick waiting for Confirm is withdrawn and the business's notice enqueued, and no new pick is taken until the pause ends; the Confirm refusal is T224's and the still-open email T094's (D-491). A "<number> YES" text pick is accepted only after a text ending "By picking, you agree to the Terms: askhava.com/terms" was sent for that job; the send of that Terms line is recorded (job, time, template version) and the pick is logged with the channel "text" (PICK-016's text half; the page half is T055's, D-492).
