## Overseer workflow (what worked today)
1. **Number:** `python3 -m runner --reserve-decision --reason "..."` before writing the entry.
2. **Plan change:** builder on `claude/plan-<slug>` in a fresh worktree from `origin/main` → independent Opus review (two rounds for anything touching security or money) → fixes → PR. A plan PR that edits QUEUED tasks opens **without** auto-merge.
3. **Before merging a plan PR,** re-read every edited task's state on `claude/kit-state`. Never edit an IN_PROGRESS or MERGE_PENDING task or one with a `resync` mark; if one got claimed while the PR waited, drop that task's edit from the PR and note it in the decision (as D-3079 did for T348). Then merge with `merge_pull_request` (squash, `expectedHeadSha`).
4. **After a plan fix for a BLOCKED task:** `python3 -m runner --requeue T### --plan-fix D-#### --reason "..."` from a fresh `origin/main` worktree.
5. **"Merge conflicts" on a branch:** merge `origin/main` into it (never rebase, never force-push), resolve, `git grep -n -E '^(<<<<<<<|=======|>>>>>>>)'` must find nothing, then commit and push. `docs/decisions.md` is append-only: the branch's own entries go after `main`'s.
6. **A false `PLAN GAP:`** (reviewer not confirming, as T334): `--requeue T### --reason "..."` while attempts remain.
