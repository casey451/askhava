## Lessons (new)
- **A stacked plan branch** (built on an open plan PR) merges cleanly after the squash. Use `git merge -s ours origin/main` when main's tree equals the base PR's head; verify with `git diff <base-head> origin/main` being empty. `merge_main.py` refuses there because of `kit/tasks.json` hunks.
- **The `--plan-fix` requeue** allows exactly one more attempt per decision. A wasted attempt (a stale claim) needs a new decision listed in the task's `decisions`.
- **Resumed builder and reviewer agents** carried four plan PRs this session at far lower cost than fresh ones. Their context grows, so start fresh agents in a new session.
- **The reviewer caught real defects every time:** client-trusted consent wording, cross-business outcome credit, a mask that would have hidden money amounts, emergency texts blockable by a counter fault. Never skip round 2 for privacy, money or consent changes.
