## Lessons

1. **A new decision with a `partial` supersede re-pastes the old decision into every prompt that carries it.** Regenerate all of them, not only the touched tasks (`gen_prompts --check` catches it).
2. **After a squash merge of a plan PR whose branch another plan branch was built on, union merge duplicates the decision entries.** Take main's `docs/decisions.md` and re-append the branch's own entries.
3. **Pushing to a PR branch does not cancel its auto-merge, but a branch that falls behind main does not merge** (strict up-to-date). Resync right after a task squash.
4. **`update_trigger` and `delete_trigger` are refused in a scheduled run** except in a turn that answers Casey. Use `send_later` for checks and let stale ones fire harmlessly.
