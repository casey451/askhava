## Gotchas (learned Nov 5–6)
- **Merging `main` into a plan branch after another plan PR lands:** plain merge (no rebase), then put `main`'s new decision lines **before** the branch's own entries in `docs/decisions.md` (the append-only check compares against `main`); commit the reorder as its own commit. Move any `docs/decisions.md:NNNN` citations the reorder shifts.
- **Force-push** is denied by the permission classifier and forbidden by the rules: add commits instead.
- **Stop hooks** that report "unpushed commits" or "unverified commits on main" are stale tracking refs or GitHub squash commits: refresh with `git fetch origin +refs/heads/X:refs/remotes/origin/X`; never amend or push `main`.
- **Git stash is shared across worktrees**: never run a bare `git stash`.
- **Disk:** remove merged worktrees with `git worktree remove` to free their cargo target dirs.
