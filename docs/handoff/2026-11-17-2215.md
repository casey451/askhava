## Lessons

2. **Never let a calendar date fail a check that runs on main or the nightly** (D-4223 round 2): nothing to revert.
3. **Open-ended negative scans keep failing review** (T104, T115 after T111/T112): close the list in the plan before the first claim, with planted must-fail/must-pass sentences and a prototype run over main's files.
4. **Fold approved plan branches into one PR** to move main once (#978, #986): merge the second branch in, keep decisions in numeric order, JSON-union `kit/tasks.json`, verify each task's entry equals its source branch.
