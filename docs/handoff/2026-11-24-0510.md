## Lessons

- **ChatGPT's diagnosis was wrong:** a flake root cause it named did not reproduce in 3,500 trials. Always verify with a real run when one is cheap; Chromium and Playwright are preinstalled in the container.
- **Union-merge duplicates:** a plan PR that touches crate NOTES.md files can get duplicate lines when a task edits a line in place. `check_code_docs` catches it.
- **Gaps in `validate_tasks`:**
  - A build task may not change another task's test; make it `harness` (the worker model can stay Sonnet).
  - A new task owning a file that DONE tasks owned needs those tasks in its `deps`; the validator lists them one at a time.
