- **Plan-gap routine (D-2859):**
  1. A worker's `PLAN GAP:` report blocks the task, and the outbox gets `T###-plan-gap`.
  2. Read the report and `last_failure`.
  3. If the report is mistaken and attempts remain, use plain `--requeue`.

  6. Then run `python3 -m runner --requeue T### --plan-fix D-#### --reason "<why>"`.
