## Lessons (read before acting)
1. **`merge_main.py` must match `- **D-` entries.** Decision entries start with `- **D-####**`, not `## D-`. The helper as first written replaced the branch's decisions.md with main's copy and dropped the new entry; it is fixed now. Recreate it with that pattern.
2. **The reviewer caught the overseer's own wrong premise.** My scout brief told T477 to report returned notes as "not stored", which would have weakened OPS-039. Brief reviewers with the code, never your conclusion.
3. **Check what a 2xx proves.** The app's Stripe webhook answers 200 and does nothing when the envelope fails to parse (for example, a missing `livemode`). An e2e or contract test must check the effect, never only the status.
4. **Scout size estimates are rough.** The line counts were unverified guesses. D-3805's turn-fit model decides splits, so don't re-split on a scout's estimate alone.
5. **Copying a helper between spec files is duplicate logic.** Move it into a shared module the task owns instead. T100's new `check_duplicates.py` would flag a copy, and T100 owns only `app/` and `migrations/`.
6. **Resumed builder and reviewer agents are cheap.** One builder and one reviewer carried three plan changes and nine review rounds this session. Their agent IDs don't carry over to a new session.
