## Worker: read this first (unsure points; check before relying on the draft)

1. **"Private helper" means `pub(crate)`, not bare `fn`.** The goal puts the helper in `conversation.rs` and its unit tests in `app/intake/src/tests/conversation.rs`, which is the sibling module `crate::tests::conversation` (`app/intake/src/tests/mod.rs:5`). The other choice is a `#[cfg(test)]` module inside `conversation.rs`, but the goal names the test file, so do not use it.
2. **The existing `Ok(None)` for an already-closed request stays.** `conversation.rs:305-307` answers `Ok(None)` when `models::close_request` finds the request already closed ("the reply goes once"). The unit test at `tests/conversation.rs:366-369` asserts this (`again == None`). The goal's "never answers `Ok(None)` for an under-age age" means that a refusal never turns into `Ok(None)`. It does not mean the once-only rule goes away. Leave `:305-307` and that test as they are.
3. **No guard refuses this text yet.** `queue_text` (`conversation.rs:585-610`) has no guard on main. T857 adds it later. So `NoConsent` cannot be produced end to end in this task, and the helper's unit tests are the only cover for the new branch. T857's refused-text test proves the end-to-end path (`docs/handoff/drafts/T857.md:40` point 11, test at about `:622-640`). Do not add a guard, a test-only switch or a fake `NoConsent` path to `queue_text`.
4. **The transaction stays usable after `NoConsent`.** The guard returns `NoConsent` as a value (`app/intake/src/consent_guard.rs:56-78`) after a plain read (`models::consent_records`), so `tx` is not left aborted. A failed guard SQL statement comes back as `IntakeError::Database`, which stays `Err` and rolls back. This is correct. No savepoint is needed.
5. **Do not intra-doc-link the `pub(crate)` helper from the `pub` `stop_if_under_18` doc.** That trips `rustdoc::private_intra_doc_links` if docs are built with warnings denied. Name it in plain backticks.

/// INT-038, PRIV-008, D-5982: the age stop's text as [`stop_if_under_18`] keeps it. A queued
/// text passes through; a text the consent guard refused ([`IntakeError::NoConsent`]) is `None`,

        Err(other) => Err(other),
