## Lessons from tonight

- **A plan-fix requeue needs the decision in the task's `decisions` list on `main`.** `--plan-fix D-x` is refused otherwise, and a plain `--requeue` is refused after 3 attempts. A task blocked by an outside failure (an advisory, a host port) still needs a small plan change (decision plus goal note) before it can run again.
- **Reserve decision numbers with `python3 -m runner --reserve-decision --reason "..."`**, not by hand.
- **Check the next free task ID on `origin/main` right before pushing.** The T831 ID collided between two branches; it was renumbered to T832.
- **When several tasks fail on the same CI step, check `main` first.** Reproduce the audit with `ci.yml`'s pinned cargo-audit/cargo-deny tarballs. The runner's smoke does not catch a new advisory, so `main_red` is not set.
- **Merging `main` into a plan branch can leave the branch's decision above `main`'s new one.** Reorder so `main`'s file is the prefix, then rerun `check_pr_change.py --base origin/main` after the commit (it reads HEAD, not the working tree).
- **A failed check on a superseded commit of a PR** is not the PR's state. Check the head SHA's run.
