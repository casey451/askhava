- **AI-019** AI-written words are limited: the AI may reword the next question-bank question, ask one follow-up the set's expert brief allows, write the job card and the project file from the scrubbed request, answers and photo notes, and write the INT-046 image prompt; it never diagnoses, names a cause, prices or estimates cost, judges safety or urgency, recommends or mentions any business, promises an outcome, or adds a fact the homeowner didn't give; code checks every AI output for contact details (CARD-008), dollar amounts and prices, cause words ("probably", "likely", "sounds like", "needs a new", "the problem is"), the WORD-022 phrases and the WORD-003 claims, and any failure falls back to the fixed template or her own scrubbed words; every AI-written card is approved by the homeowner or auto-sent only after she was shown it (INT-041) (D-430). - **AI-020** The expert brief AI-019 refers to is the job type's entry in `docs/catalog/expert/<category>.yaml`: `catalog` loads every expert file at start-up and refuses to start when one fails the checks `scripts/check_expert.py` runs on references (its category is enabled, each `bank_job_type` is a job type of that category, each job type `id` exists in its `kb_trade` file unless marked `new_job_type`, each shared follow-up id resolves, each `quote_format` matches the category); while the AI switch is on (AI-008) the Ask call gets the request so far, the question set and the chosen job type's `must_know`, `allowed_follow_ups` and `urgency`, and the Write call gets its `card_template`, `scope_line_en`, `photo_reading` and `never_say`, as `docs/catalog/expert/PROMPT_ASSEMBLY.md` assembles them, never a whole file; the AI names its one follow-up by id from that job type's `allowed_follow_ups` and code takes the text and options from the file, so a follow-up id not on the list is dropped; an AI output holding a `never_say` line of its job type fails the AI-019 checks and falls back; a follow-up's Spanish text is used only once the TXT-003 review of that file is recorded, and until then a Spanish request gets no follow-up; an enabled category with no expert file gets the question set alone; the expert files never decide routing, fees, the INT-004 text or who gets a card (LIC-043, D-436) (D-479, D-480).
