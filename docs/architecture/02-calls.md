# Architecture section 2 notes: `calls`

Moved here verbatim from `docs/architecture.md` (D-6022), whose index lists every part. Until T885 makes `docs/architecture/` a shared path, a task adds new notes to the index, at the end of the section this part came from, and the next plan change moves them here.

The section 2 notes ("Processes and code layout") whose first named crate is `calls`, in their original order.

- Safety voice call switch stored (T407, D-3134, D-4721; CALL-019, CALL-022, SEC-043, CON-031, TXT-024): new append-only table `calls.safety_switch` (migration 0203; app role SELECT and INSERT only; on rows hold the attorney approval's date and reference, off rows neither; the newest row is in force, none is off). `calls::safety_switch` gives `safety_switch(conn)` (an on row read back through `SafetySwitch::turn_on` with the compiled-in `SAFETY_CONDITIONS`), `safety_approval`, `turn_safety_switch_on(conn, owner, (&Approval, &Conditions), now)` and `turn_safety_switch_off`, each change one row and one `calls.safety_switch_changed` audit row (IDs and on/off only) in one transaction under an advisory lock. Readers: the worker's `calls.safety_call` handler on every run (no main number: completes with no call), `server::inbound_text::handle` per message (`safety_call_on` for the consent text and the paused-emergency plan), and `portals::owner_portal` (a new `portals` to `calls` call), whose `POST /owner/safety-call` (`owner_safety_call`, fresh factor `OwnerAction::SafetyCallSwitch`) turns it on or off; a refusal is a 400 naming the missing approval or unmet CALL-022 items.
- Main number greeting (T688, D-4361, D-5534, D-5924; CALL-020): `RouterParts::with_main_number`, set by `main` from `settings.main_number()`, keeps an `Extension<inbound_voice::MainNumber>` that `webhook_routes` layers on the voice route alone; `inbound_voice` answers a verified call to that number with `calls::api::greeting_twiml` (no `Record`, `Dial` or voicemail verb, nothing stored); without the layer, or with no number set, it hangs up as before.
