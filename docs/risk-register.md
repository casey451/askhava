# Ask Hava risk register

**Adopted:** October 28, 2026 (D-479). Rules: `docs/governance.md` section 9. Every open risk has an ID, an owner, the mitigation already in the plan, and a resolution criterion a tool run or a written answer can satisfy. Closed risks keep their row with the dated evidence. Severity is for the build and the launch, not for the business case, which `docs/PREBUILD.md` section 7 covers.

Owners: **Claude** (a plan-change session or the task named), **Casey**, **automatic** (the build proves it in `Ci`, nightly or the runner), **outside** (a vendor or agency answer).
