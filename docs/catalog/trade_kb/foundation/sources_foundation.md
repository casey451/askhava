# Sources: Foundation Files (Ask Hava Trade KB)

Numbered source list for `az_license_master.md`, `part1_all_reasons.md`, `part3_photo_playbook.md` and `schema.yaml`. Trade files may cite these IDs. Add new trade-only sources in the trade file's own `sources:` list.

Status key:
- **F** = fetched and read this pass.
- **C** = copy fetched from a mirror (official site blocked automated access).
- **Snip** = search-result snippet only; open the page before quoting.
- **3P** = third-party, non-official; context only.

Local copies of fetched text are in `/workspace/homerepair/trade_kb/sources/` (for example `r4-9-103.clean.txt` and `ars32-1121.clean.txt`).
